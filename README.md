# MIZZLI FC

App ufficiale della squadra: rosa, calendario, formazione, convocati, voti giocatori e pannello admin.

## Avvio

```bash
npm install
npm run dev
```

## Accesso Admin

- **Utente:** Noldi
- **Password:** Noninoni99@

## Funzionalità

- Rosa e schede giocatore
- Calendario e pagine partita
- Formazione sul campo (titolari, panchina, staff)
- Voti 1–10 per partita (utenti loggati)
- Convocati, classifica, live, shop, galleria
- Login email, SMS e Google (opzionale)
- Admin per colori, rosa, partite e club

## Stack

- Next.js 16 + React 19
- Tailwind CSS 4
- Dati in `data/` (JSON) + upload immagini
- Capacitor iOS
